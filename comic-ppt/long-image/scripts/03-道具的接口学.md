## 【全局风格设定 · 每集通用，务必严格遵守】

### 成品形态与生成流程
- 最终成品是**一张手机长图漫画**：宽度恒为 **1080px**，垂直向下滚动阅读，**全彩**，高清。
- 不要尝试一次生成整张长图。必须按【逐段脚本】拆成多段分别生成：每段是一张 1080px 宽、高度 1440–2160px 的竖版图片（按内容多少定高，高清渲染）。
- 全部段落生成后，按段序**垂直无缝拼接**为一张完整长图。拼接处不得出现白缝、错位或重复内容。

### 顶部与底部安全区（仅首尾两段）
- 仅在整张长图的**最顶部**留出 ≥200px、**最底部**留出 ≥200px 的安全高度：两处为背景/场景的纯净延展（不是白色边、不放任何人物、文字、道具），用于躲避手机状态栏、刘海屏、标题栏与底部手势区的遮挡。
- 除首尾两段外，其余各段上下边缘**满幅出血**，段与段之间不留任何空隙。
- 每段的上下接缝必须落在斜切格线、场景色块或天空/夜色上，**禁止接缝切过人脸、对话气泡或文字**。

### 画风
藤子·F·不二雄经典哆啦A梦角色形象 + 现代科技杂志编辑插画（editorial illustration）质感。角色为简洁粗线条漫画风，背景与信息图采用扁平化、等距线框、细腻网点纹理。整体是「印刷精美的技术杂志」，不是儿童绘本。全彩画面，高清、锐利、矢量感，2K 分辨率质感，禁止黑白稿与低分辨率感。

### 统一色板
主色哆啦蓝 `#2B9FE3`、深蓝 `#1B5FAA`；底色米白纸感 `#FAF6EE`；强调橙 `#FF8C42`；正文墨黑 `#222222`。架构图使用蓝白线框 + 橙色高亮关键路径；代码一律深色终端卡片（`#1E1E2E` 底、浅色等宽字）。夜景与情绪场景可用深蓝渐变，但每段都必须保持彩色。

### 动态分镜规则（长图的灵魂）
1. **禁止横平竖直的均分宫格**。每段 3–5 格，格子大小错落，主格占该段画面的 40–60%。
2. 格线必须动起来：斜切面板、锯齿/闪电形分割线、弧形格、梯形格交替使用；允许「破格」——角色、道具或光效探出格线 10–20%，制造冲击力。
3. 阅读动线永远自上而下：用斜切格线的指向、虚线动线、角色视线与色块流向，把视线从每段顶部引到底部，再自然滚入下一段。
4. 版式库（每段从中组合选择，禁止连续两段使用同一版式）：斜切双格、上大下小锯齿分割、出血大图 + 浮动旁白框、左窄右宽梯形双格、纵向时间轴三格、中心辐射、Z 字动线三格、满宽全景格。
5. **画面必须充实**：每一格都要有具体场景环境（办公室、会议室、深夜街道、全息空间……）、角色动作或信息图，禁止大面积空白背景，禁止「一格一个人头 + 一句话」的敷衍构图。
6. 角色在单格内不超过画面 1/2，以全身/半身的场景化姿态出现（坐着敲代码、站在白板前、围着工位）；禁止大头像特写撑满整格。
7. 每段保留一个「视觉钩子」：一道斜切色块、一个出血的道具、一条贯穿的虚线动线、一片发光特效。

### 文字规则（手机阅读的生命线）
1. 全部使用中文，技术术语保留英文原词（如 plugin、loop、session）。
2. 字号按 1080px 宽画面计，必须大且清晰：封面主标题 96–120px；剧情小节题字 64–80px；旁白框与正文 40–48px；对话气泡 40–44px；最小的图注标注也不得小于 32px。
3. 对话气泡每句不超过 20 字，但每格可以放 2–4 个气泡形成对话回合，让故事娓娓道来。
4. 旁白一律用漫画式色块旁白框（米白底或深蓝底白字），贴在格子的上缘或下缘；禁止整段文字墙，禁止一段全是字没有画面。
5. **禁止出现任何页码与编号文字**：不写「第 X 页」「第 X 段」「第 X 格」，不写 01、02 之类的序号。剧情衔接用手写感题字（如「当天深夜」「周五下午」）或纯场景过场格。
6. 架构图采用等距线框风格，节点用圆角矩形/圆柱体，箭头标注数据流，关键路径橙色高亮；架构图必须**纵向分层**（自上而下），角色站在图旁的瞭望台或地面上仰望、指点。
7. 代码/伪代码用深色终端卡片，带行号和语法高亮，卡片一角可有迷你角色注释气泡；卡片上的代码必须与脚本所写**逐字一致**。

### 屏幕呈现规则

## 【本集设定】

- **本集目标**：讲透 deepseek-harness 最重要的结构化设计——能力缝（capability seam）三角色模型，用 shell seam 这个教科书案例讲清「换实现不改工具」如何成立。
- **研发收获**：掌握 Definition / Provider / Consumer 的分包规则与依赖红线（只依赖 Definition，永不依赖具体 Provider）；理解 `resolve(request): Spec` 的显式默认化模式。
- **领导收获**：理解「合规要求把执行环境迁到沙箱」这类变化，在 dsh 里是一行配置的事，而不是一个季度的重构——架构弹性直接折算成响应成本。
- **故事梗概**：公司安全审计风暴——老师宣布：所有 AI agent 的命令执行必须一周内迁到隔离沙箱，胖虎的「裸奔服务器」被当场点名。小夫幸灾乐祸说大雄的工具层全部要重写。大雄连夜加班，哆啦A梦却带他去喝咖啡：「道具换一枚就好，为什么你觉得我要重做一只手？」
- **出场角色**：大雄、哆啦A梦、老师、小夫、胖虎、出木杉、静香（选道具）
- **结尾钩子**：迁移顺利完成，但大雄在复盘时发现一个诡异问题：agent 明明执行了命令，重启后却「完全不记得」自己做过什么 → 引出下集会话日志。

- **画布**：1080 × 1920px。上下缘满幅出血；上接缝落在传送带光效，下接缝落在结论条。
