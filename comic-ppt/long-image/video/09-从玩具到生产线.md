# 第 09 集《从玩具到生产线》连续动态漫画视频脚本
## ACP / SDK 协议、examples、工程纪律与企业落地路线图（全系列大结局）

> 本文件是可独立制作的完整视频脚本。它将静态长图素材重构为有动作因果、空间连续、信息逐步揭示与镜头穿越的动态漫画，不沿用段落或宫格结构。

## 一、本集故事设定
季度评审会上，技术总监老师不再接受“demo 能跑”的答案。他要求团队解释：如何让 DeepSeek Harness 接入 CI、IDE 与企业数据平台，如何安全管理凭据与高权限能力，又如何在开发者预览阶段建立可控的采用路线。大雄第一次担任主讲，哆啦A梦负责把抽象协议变成可见的交通系统，出木杉展示工程门禁，胖虎承担安全质询，静香从产品验收角度追问，小夫代表“标准协议至上”的直觉。众人最终把一个实验室玩具，搭成通往生产线的桥；散会后，大雄获得“22 世纪架构师结业证书”。结尾不设下集钩子，以研发与决策者资源封底完成全系列收官。

### 叙事目标
- 研发观众：分清 headless、ACP、SDK 的入口、输出与适用场景；能从 examples 起步；理解凭据、安全边界和工程门禁。
- 决策观众：获得“试点—集成—平台化”三阶段路线图，以及开发者预览、会话格式、外部 API/密钥、高阶能力边界四项风险及缓解策略。
- 情绪弧线：评审压力 → 路线澄清 → 安全质询 → 工程信任 → 决策落地 → 温暖收官。

## 二、世界与背景设定
故事发生在“野比科技”近未来研发园区。现实层是会议室、CI 机房、开放办公区、天台与城市生产线；解释技术时，会议桌中央的 DeepSeek Harness 蓝图会展开为“协议交通城”“examples 装配站”“水下工程桥墩”“插件星系”和“三阶段阶梯”。这些空间不是独立幻灯片，而是从上一场景中的真实物件连续变形：桌面光线变车道、终端字符变列车、事件流变瀑布、桥墩上升成阶梯。所有全息屏均无浏览器或操作系统窗口外框。

藤子·F·不二雄经典哆啦A梦角色语汇，融合现代科技杂志 editorial illustration：角色用简洁粗线条和有限帧动画，环境与信息图用扁平化等距线框、细腻网点纹理、清晰矢量边缘；成熟、精密，不做儿童绘本感。主色哆啦蓝 `#2B9FE3`、深蓝 `#1B5FAA`，底色米白纸感 `#FAF6EE`，强调橙 `#FF8C42`，正文墨黑 `#222222`；终端卡片固定为 `#1E1E2E` 底、浅色等宽字。风险段仅增加警示红 `#E34B4B`，不可替代主色体系。架构节点蓝白线框，当前路径橙色高亮；夜景为深蓝渐变但保持全彩。
## 五、视频规格
- 画幅：9:16 竖屏，1080×1920，24fps，Rec.709；字幕与关键字保留在四边 8% 安全区。
- 建议总时长：**05:30（330 秒）**，共 36 个连续镜头；可在不删技术内容的前提下上下浮动 10 秒。
- 动画方式：角色以 2D cut-out + 逐帧表情口型，技术空间以 2.5D 多平面景深、等距信息图和粒子数据流；镜头运动保持 24fps 连续，角色有限帧可按 12fps 制作。
- 交付：主片、无字幕版、M&E 音乐音效版、对白干声版、SRT/ASS 字幕、关键技术画面静帧。

## 六、动态化原则
1. 每个镜头至少发生两类变化：角色动作/表情、机位或焦点、节点点亮、光线或环境状态；禁止静态图上平移念字。
2. 动作必须跨镜承接：上一镜抬起的笔、飞出的光点、转动的门把手，必须在下一镜以相同方向、速度或落点继续。
3. 技术信息遵循“问题出现 → 路径生成 → 节点逐一点亮 → 数据实际流过 → 结果反馈”的因果链；不一次展示完整图。
4. 信息图均可进入：镜头沿数据流推进、穿越协议门、潜入桥墩、绕行插件轨道；文字标签在对应实体被触发后才出现。
5. 层级建议：前景为人物手势/桌沿/粒子，中景为当前节点与行动，后景为会议室或技术空间；关键数据流独立发光层，遮挡关系明确。
6. 对话期间仍保持细微表演：呼吸、眨眼、视线转移、手指停顿、服装与纸张惯性；不得“定格嘴动”。
7. 转场服务因果：红笔划线变车道、终端光标变列车灯、事件瀑布落入桥下水面、风险警示带卷成夕阳云带；不使用无意义模板转场。

## 八、配音与字幕规范

- 普通叙事语速 4.0–4.5 字/秒；技术术语与命令前后各留 2–4 帧呼吸，风险与路线图段降至 3.6–4.0 字/秒。
- 旁白为中性、可信、略带技术纪录片质感的中青年声线；不抢角色戏，关键结论只重读一次。

- **音乐主题**：开场“跨桥主题”用木琴、弦乐和轻电子鼓；协议城使用有方向感的合成器；安全质询与风险清单降为低频脉冲；工程桥墩用沉稳弦乐；天台与封底回归木琴主题并完成终止式。
