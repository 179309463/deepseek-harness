# 第 6 集｜换装照相机与审批单（连续动态漫画视频脚本）
## profile / bundle / patch / preset——同一内核的千种形态与它的缰绳

> 本文件是可独立交付给导演、分镜、原画、动画、配音、声音与后期团队的完整制作稿。它不是长图分页或静态宫格改写；全片以动作因果、视线匹配、运动接续和镜头内状态变化构成连续叙事。

## 一、本集故事设定
- **本集目标**：讲清 dsh 的配置组合体系、启动时插件树的四层叠加、per-session preset，以及 permission preset 与 approval 如何构成企业治理面。
- **故事梗概**：野比科技必须同时上线研发 Web 工作台、CI headless 质检 agent、外包受限版。大雄误以为要维护三套代码；哆啦A梦用“换装照相机”证明同一 Cordis 内核可由 profile、bundle、patch 组合成不同产品，再由 preset 给单个 agent 会话换装。胖虎申请 `danger-full-access`，被老师以 fail-closed 审批制度驳回。最终三套形态同时上线且代码零分叉。
- **戏剧主线**：三套需求压顶 → “三套代码”误解 → 换装照相机揭示配置组合 → preset 深入到单会话 → 胖虎越权制造冲突 → approval 解释默认安全 → 三线同时上线 → 巨型任务引出 subagent。
- **研发收获**：理解 profile bundles → profile patch → home patch → `--patch`；理解 `dsh-base`、`dsh-web-app`、`dsh-headless`；理解 preset 的挂载、隔离、回滚与选择事件；掌握 `!!js` 与 overlay 边界。
- **领导收获**：理解“同一内核、配置成产品”的维护收益，以及沙箱、审批、白名单、留痕和 fail-closed 如何成为出厂治理能力。

## 二、世界与背景设定
- **时代与地点**：近未来的“野比科技”，现实办公室、CI 机房、外包区与具象化全息技术空间并存。配置、事件和数据流都能被角色看见、触碰，但其技术含义必须准确。
- **连续空间**：主会议室与总控室相邻；走廊连接老师办公室、研发区、机房观景窗。换装照相机的蓝色光轨承担现实空间与抽象配置空间的连续转场。
- **技术世界规则**：Cordis 是唯一“身体/内核”；bundle 是装备包，profile 是衣柜/进程组合，patch 是精确修改贴纸，preset 是单个 agent 会话的装备柜。抽象隐喻只帮助理解，不改变源稿定义。
- **时间**：同一工作日早会开始，下午完成配置与权限评审，周五上线日收束；审批灯塔段是老师讲解时展开的抽象夜海空间，不是另一天。

## 五、视频规格与动态化原则
- **画幅与帧率**：9:16，1080×1920，24fps；母版保持 2K 矢量质感，最终建议时长 **05:38**。
- **安全区**：关键信息置于左右各 72px、顶部 150px、底部 210px 内；字幕基线距底部 230–300px，避开平台按钮区。
- **镜头原则**：每镜至少发生一次可见状态变化；角色必须有起势—执行—收势，禁止“站定说话”的静帧。动作到动作剪辑优先，推、拉、摇、移、环绕须服务因果。
- **连续性原则**：上一镜动作方向、视线或飞行物必须在下一镜同方向接住；抽象空间通过换装照相机光束、触控笔轨迹或审批章冲击波进入和退出。
- **信息图动态化**：严禁整张架构图一次出现。节点按叙事顺序点亮，连线随后生长，数据光点再沿线穿越；层级图必须表现“空列表 → bundle → patch → home patch → CLI patch”的实际变化。
- **动画层级**：角色线稿与上色为中景层；前景允许文件、光粒、设备边缘形成视差；背景至少两层缓慢漂移。数据流、文字、图标均独立图层，可做遮挡和景深。
- **文字节奏**：术语先由动作建立隐喻，再在屏幕上出现准确原词；每次最多突出一个主概念，长列表按项点亮，不一次堆满。

## 十、动画执行说明
- **角色动画**：常规以 12fps on twos 制作，快门、盖章、纸张撞击、数据光点冲刺切到 24fps on ones；口型至少覆盖闭口/中口/大口并匹配重音。眨眼、呼吸、手指停顿不可缺失。
- **镜头内变化最低标准**：每镜同时至少包含“主体动作变化 + 环境/信息状态变化”两类变化；如人物静止讲解，则信息节点必须持续按因果点亮，且人物有视线、手势、重心转移。
- **信息图执行顺序**：标签淡入不等于动态化。必须遵循“容器出现 → 节点生成 → 连线生长 → 数据点穿越 → 结果反馈 → 日志落盘”。回滚则严格逆序熄灭。
- **景深与视差**：前景纸张/门框/镜筒 1.2× 速度，中景角色 1×，背景办公室/机柜 0.5×；抽象空间的远端节点 0.25×，避免平面 PPT 感。
- **光效控制**：快门闪白不超过 4 帧且亮度平滑，避免刺激；红色只用于危险、驳回和关闭，不拿红色装饰普通节点。
- **文字动画**：代码逐行出现必须给足阅读时间；四层叠加每层至少停留 36 帧；四种 approval 结果每项至少 24 帧；长路径按语义分组高亮，不整体缩小。
- **资产复用**：Cordis 内核、三种 bundle、权限卡、approval 日志节点建立统一组件资产；同一事件在不同镜头不得更换图标、颜色或端口位置。
