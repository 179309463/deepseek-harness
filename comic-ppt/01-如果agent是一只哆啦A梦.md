### 画面与版式硬性规则（防低质的关键）
1. **角色不超过单页画面的 1/3**，禁止大头像特写撑满页面；角色只在剧情页和对话气泡旁出现，且为全身或半身场景化姿态（坐着敲代码、站在白板前、围着工位）。
2. **每页 3-6 个信息块**，正文文字每页不超过 120 字，对话气泡每句不超过 20 字。
3. **禁止呆板的横竖四宫格/六宫格均分布局**。每页从以下版式库中选择：对角线分割、斜切面板、杂志式不对称网格、左侧竖栏导航 + 右侧主视觉、出血大图 + 浮动文字卡片、跨页式横向时间轴、中心辐射图、Z 字形阅读动线。
4. **禁止「一页一张大插图 + 底部一大段文字」的小人书版式**。信息必须以标题、要点列表、标注引线、迷你图表的结构化方式呈现。
5. 架构图采用**等距线框风格**（isometric line art），节点用圆角矩形/圆柱体，箭头标注数据流，关键路径橙色高亮。
6. 代码/伪代码用**深色终端卡片**，带行号和语法高亮，卡片一角可以有迷你角色注释气泡。
7. 每页保留一个「视觉钩子」：一道斜切色块、一个出血的道具、一条贯穿页面的虚线动线，制造冲击力。
8. 文字用中文，术语保留英文原词（如 plugin、loop、session）。

### 禁止事项
- 禁止角色占满画面、字体巨大、分辨率感低
- 禁止整页纯文字或整页纯插图
- 禁止无剧情动机的生硬说教
- 禁止四宫格式平均切分

## 【本集设定】

- **本集目标**：让零基础读者理解什么是 agent harness、deepseek-harness 是什么、为什么「一切皆插件」是颠覆性的。
- **研发收获**：建立 loop / tools / session 的最小心智模型；知道 `npx @deepseek-ai/dsh web` 能跑起来什么。
- **领导收获**：理解这个项目的定位（DeepSeek 开源的 agent 基础设施，MIT 协议，2026 年 8 月发布，对标 Claude Code / Codex 的底层运行时而非复刻），以及它对团队的技术选型意义。
- **故事梗概**：大雄入职野比科技第一天，接手祖传单体 agent「铁雄一号」——三千行代码缠成一团，改一行崩三处，被老师批评。深夜，哆啦A梦从抽屉里出来，没有直接帮他改代码，而是从口袋里掏出 DeepSeek Harness，告诉他：「问题不在你的代码，在于你的框架没有『口袋』。」
- **出场角色**：大雄、哆啦A梦、老师（电话中）、小夫（炫耀）
- **结尾钩子**：大雄问「口袋到底是怎么装下这么多道具的？」→ 下集讲 Cordis 内核。

### 第 6 页 ｜ 心智模型：agent 的三件事
- **版式**：中心辐射图。中心是等距线框的大脑图标，向外辐射三个分支面板，呈 120° 分布（非均分宫格）。
- **画面**：中心大脑发光；三个分支面板分别是：循环（Loop，环形箭头）、工具（Tools，扳手与终端）、会话（Session，卷轴日志）。哆啦A梦和大雄缩在右下角看着这块「展板」，体型很小。
- **文字**：
  - 标题：任何 agent 都在做三件事
  - 分支一：**Loop 循环** —— 想一步、做一步、看结果、再想下一步
  - 分支二：**Tools 工具** —— 读写文件、执行命令、搜索网页的手和脚
  - 分支三：**Session 会话** —— 记住发生过的一切，让下一步思考有据可依
  - 底部一行结论：deepseek-harness 的答案是：这三件事，连同它们的所有零件，**全部是插件**。
- **技术点**：对应仓库的 `core/agent-loop`、`core/tools`、`core/session` 三个核心包——但它们都不是特权内核，而是可替换插件。

### 第 10 页 ｜ 深度页：为什么是 Cordis？
- **版式**：左侧竖栏写「时空可组合性」五个竖排大字，右侧上下两个信息块（非均分：上 2/3 图文，下 1/3 引用卡片）。
- **画面**：右上——出木杉站在白板前，白板上是插件随时间挂载/卸载的时间轴图示（空间组合 + 时间组合两个维度）。右下——一张引用卡片，深色底。
- **文字**：
  - 标题：底座论文：时空可组合性
  - 上部要点：
    - **空间可组合**：插件之间声明式依赖（inject），谁依赖谁一目了然，按依赖顺序自动挂载
    - **时间可组合**：运行中可以动态加插件、拔插件，系统不重启、不崩溃
  - 气泡（出木杉）：VS Code 的插件也有依赖声明，但几乎没人用；dsh 把这件事做成了地基。
  - 引用卡：Cordis 的设计出自论文《A Programming Paradigm for Spatiotemporal Composability》——为「持续被修改、甚至自我修改的系统」而生
- **技术点**：Cordis 是 vendored（源码级内置）进仓库的框架层，可审计、可打补丁、版本锁定（见 `vendor/README.md`）。
