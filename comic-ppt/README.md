# 哆啦A梦讲 deepseek-harness —— 漫画 PPT 系列总导读

> 这是一套 9 集的深度技术漫画 PPT 系列脚本，面向**研发技术人员**与**部门领导**双受众。
> 每个 `0X-*.md` 文件都是一个**独立完整**的 AnyGen 投喂文档：直接整篇粘贴给 AnyGen，即可生成对应那一集的 PPT。

---

## 一、系列创意设定

**核心隐喻（天然成立，不生硬）**：哆啦A梦本身就是一个 agent——

| 哆啦A梦的世界 | deepseek-harness 的世界 |
|---|---|
| 四次元口袋 | Cordis Context（插件服务仓库） |
| 口袋里的道具 | 可插拔的 Provider（能力提供者） |
| 「什么场景拿什么道具」 | `cordis.yml` 配置组合 |
| 大雄提出的愿望/任务 | 用户的 prompt |
| 哆啦A梦想办法的过程 | agent loop（turn / step 主循环） |
| 记忆面包 | 会话日志（SessionEvent Log）——本系列第 4 集会反转这个隐喻 |

**主线剧情**：大雄大学毕业后入职「野比科技」，接手了一个祖传单体 agent 框架「铁雄一号」——代码缠绕、一改就崩。来自 22 世纪的架构师哆啦A梦看不下去，用 9 次「深夜检修」带他彻底理解 deepseek-harness 的架构哲学。每集解决大雄工作中的一个真实困境，道具登场都有剧情动机。

## 四、AnyGen 使用方法

1. 打开 AnyGen，新建 PPT 任务。
2. 将某一集的 md 文件**整篇复制**粘贴进去（每个文件开头都重复携带了完整的全局风格提示词，无需额外补充）。
3. 生成后若某页不满意，把该页的「版式指令 + 画面描述」单独发回 AnyGen 重生成该页。
4. 建议按 01 → 09 顺序生成与发布；每集结尾都有「下集预告」，可自然连载。
